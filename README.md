# zhangluka

**AI 应用场景探索者** —— 关注 AI 在真实业务中的落地，不只是 Demo。

从 Harness Engineering 到 Spec-Driven Development，我在找那些**能让 AI 从"能用"变成"好用"**的关键环节。

相信好的 AI 应用不是调出来的，是设计出来的。

---

## 🚀 我在探索的方向

### Harness Engineering · 让 AI 代码真正可交付
> AI 写代码很快，但入库率很低。我在自己的 Nest.js 项目里用 OpenSpec + Ralph Loop 把 AI 代码一次性通过率从 30% 提到 75%。

[📁 查看仓库](https://github.com/zhangluka/harness_engineering) · [📖 文档站点](https://zhangluka.github.io/harness_engineering/)

### OpenSpec 内化版 · 人和 AI 的协作契约
> 基于 OpenSpec 做团队内化定制，增加 agent 适配层、工作流模板、代码审查集成。

[📁 查看仓库](https://github.com/zhangluka/OpenSpec)

### Ralph · 自动化的变更执行
> 扫描 OpenSpec changes，自动识别可执行的变更，调用 agent 完成编码。

[📁 查看仓库](https://github.com/zhangluka/ralph_npm)
